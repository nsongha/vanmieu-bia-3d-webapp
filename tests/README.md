`vdrag.mjs` (bộ lõi, r53 → r72g): các lượt chữ V của "kéo bia" cũ (kéo đều, hất, mất tay / hộp thoại giữa lượt, lướt nhanh) ở Điện

`hand:nav` bật, không phím ←/→, `body[data-hand-vnav-style]` = `hold` / `none`; view không khai báo → `aim` (có `hand:nav`).
`vhold.mjs` (bộ lõi, r72g): giữ chữ V trên bia — GIỜ ẢO (cờ `data-hand-over="stele"` do bộ thử đặt theo khung): yên 3,5 s → start
… fire ở đúng start + 2,0 s, một lần, giữ tiếp im; ngoài bia → không gì; dời tay → cancel `moved`, yên lại → đếm lại; bắn lại cần
hạ V rồi giơ lại; rời bia → `off-stele`; hạ V → `released`; mất tay 0,5 s → `lost`, 2 khung (nối) → vẫn bắn; bảng mở → `modal`,
không bắt đầu tới khi đóng; đang xoa / view đang cầm bia → không bắt đầu; rung điểm mốc → vẫn bắn; THEO CỠ TAY: tay nhỏ / to trôi
0,4 cỡ tay → bắn, 1,0 cỡ tay → huỷ, dời nhanh 0,5 cỡ tay / 0,3 s → huỷ ở cả hai cỡ; kiểu `none` / `aim` không có `hand:vhold`;
bảng đọc (`data-modal="reader"`): nắm tay → `hand:frame` fist + fistProgress 1 (không kéo bia). GIỜ THẬT trên Điện ảnh thật (view
tự đặt cờ theo tia): V yên trên bia → fire ≈ 2 s, vòng tiến độ quanh huy hiệu hiện + đầy dần, `hand:frame` lúc giơ V báo tay
(detected, `v`, x / y = tâm huy hiệu = x / y của `hand:vhold`); V ngoài bia → không gì; hạ V giữa chừng → vòng rút về tắt ≤ 0,35 s.

## Điện ảnh — `tests/cinema/`

Kiểm hành vi của chế độ Điện ảnh bằng sự kiện thật (chuột, phím) hoặc đúng **hợp đồng của lớp cử chỉ** (`hand:frame`,
`hand:sticky`, `hand:vdrag`, `hand:wave`, `input:mode`, `body.gesture-on`, con trỏ tổng hợp id 9001) và các móc DEV
`window.__vm.*` / `window.__vmHand.*` — nên không chạy trên bản build.

```sh
npm run test:cinema -- --port 5180            # cả bộ Điện ảnh (~20 phút)
npm run test:cinema -- --port 5180 --only glide,rub-camera   # chỉ vài tệp (tên tệp bỏ ".test.mjs")
npm run test:cinema -- --port 5180 --headed   # xem trình duyệt chạy
node tests/cinema/glide.test.mjs --port 5180  # một tệp, trực tiếp
```

Mỗi tệp in từng check (`✓` / `✗` + chi tiết khi hỏng) rồi một dòng `@@RESULT {…}`; trình chạy gom lại, in tổng kết và
thoát mã 1 nếu có check không đạt. Lỗi JavaScript của trang (`pageerror`) cũng tính là không đạt.

Cần: Node ≥ 20, Google Chrome đã cài. Chạy headless mặc định; GPU của máy được dùng (WebGL thật).

### Viết thêm một bộ kiểm Điện ảnh

Mỗi tệp là một script ESM độc lập:

```js
import { launch, openCinema, parseArgs, sleep } from '../lib/browser.mjs';
import { createReport } from '../lib/report.mjs';
const { port, headed } = parseArgs();
const report = createReport('ten-bo-kiem');
const { page, close, errors } = await launch({ headed, settings: { autoRotate: false, cinemaIdleAutoplay: false, handTutorial: false } });
await openCinema(page, port, { hooks: ['cinemaRub'] });
report.check('mô tả điều phải đúng', /* boolean */ true, /* chi tiết khi hỏng */ {});
await close();
process.exit(report.finish(errors));
```

Gợi ý: gieo `handTutorial: false` trừ khi đang kiểm hướng dẫn (hướng dẫn tự mở khi "khách mới" giơ tay sẽ chặn các
thao tác khác), và `cinemaIdleAutoplay: false` trừ khi đang kiểm tự trình chiếu.
